# GIPHY

> [!abstract] 整体梗概
> GIPHY 是以 GIF 动图为核心的搜索、发现、创作和分享平台，内容包括 GIFs、透明动态 Stickers、带声音的 Clips 以及动画 Emoji/Text。除网页端外，它还通过 API 与 SDK 向聊天、社交和内容产品提供搜索、热门内容与嵌入能力。

## 功能介绍

### 1. 搜索与发现

- 按关键词、反应或频道查找 GIF、动态贴纸和 Clips。
- Trending、分类和推荐适合快速寻找当下流行的表达素材。

### 2. 创作与分享

- 可上传素材或使用创建工具生成 GIF，并通过链接、嵌入或社交渠道分享。
- 透明 Stickers 更适合叠加到短视频、故事和聊天界面。

### 3. API 与 SDK

- 开发者可使用 Search、Trending 等 API，把 GIPHY 搜索接入应用。
- 测试密钥、生产环境、速率限制和内容展示要求应以最新开发者文档为准。

### 4. 内容权利

- 单个 GIF 可能包含影视片段、人物肖像、角色、品牌或用户作品。
- 平台允许搜索、分享或嵌入，并不自动授予广告、商品、再编辑或再分发权；商业项目应核对来源与权利。
