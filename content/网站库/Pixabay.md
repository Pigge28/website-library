## 功能介绍

### 1. 多媒体素材库

- 同时提供照片、插画、矢量图、视频、音乐、音效、动画和 3D 内容。
- 可按关键词、媒体类型、方向、尺寸、颜色等条件缩小范围。
- 统一素材库适合视频、网站、游戏、社交内容和演示项目。

### 2. 下载、收藏与贡献

- 素材详情提供预览、作者信息、尺寸或格式选择和下载入口。
- 登录后可收藏、关注或上传自己的作品。
- 上传者需要保证拥有内容以及必要的人物、财产和其他权利许可。

### 3. Pixabay 内容许可

- 官方许可摘要允许免费使用、通常无需署名，并允许修改或改编，但完整条款具有最终约束力。
- 禁止以基本未修改的独立形式出售或分发内容，也不能把内容作为商标、商号或服务标记。
- 含可识别商标、品牌或人物的内容可能受到额外限制，商业使用时需核对第三方权利。

### 4. API

- 官方 API 可搜索并获取 Pixabay 许可下的图片和视频结果。
- 适合建立内部素材检索、原型或内容工作流。
- 使用前应查看当前速率、缓存、署名、展示和再分发要求。

## 使用建议

1. 先选择媒体类型，再使用主题、风格、颜色和用途组合搜索。
2. 保存素材页面、作者、下载日期和当时适用的完整许可条款。
3. “免版税”不等于“没有版权”，也不代表人物、商标或财产权已经自动解决。
4. 不要原样转售、重新分发或上传至其他素材平台。
5. 音乐、音效和视频还需检查平台投诉、内容识别及项目发行渠道风险。
