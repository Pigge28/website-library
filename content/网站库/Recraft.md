# Recraft

> [!abstract] 整体梗概
> Recraft 是面向设计师、插画师和营销人员的 AI 图像生成与编辑平台，强调设计语言、构图控制、品牌风格和原生矢量输出。它可生成或编辑图片、插画、图标、矢量图和 3D 风格图形，并提供 Mockup、放大、背景移除、矢量化、擦除、无限画布和 API 等能力。

## 功能介绍

### 1. AI 图片与插画生成

- 使用文字描述生成照片感图像、插画、艺术作品和营销视觉。
- 可选择不同模型、样式、比例和生成方向，再在画布中迭代。
- 对复杂场景、构图和图像内文字提供面向设计的控制能力。

### 2. 原生矢量与图标

- 支持从提示词生成可编辑、可缩放的 SVG 矢量内容。
- 适合图标、标识草案、插画、贴纸、T 恤和游戏资产设计。
- 导出前应检查路径结构、字体转曲、节点质量和实际印刷适配性。

### 3. 图片编辑与生产工具

- 提供图片放大、背景移除、图片矢量化、AI 擦除等工具。
- Mockup 生成器可用于快速呈现包装、服装或商品视觉。
- 无限画布与实时协作适合组织多个方案和品牌风格方向。

### 4. API 与团队工作流

- API 可用于图像或矢量生成、编辑、背景移除和批量任务。
- 企业与团队功能面向协作、品牌一致性和高频生产。
- 接入前应核对模型、额度、输出格式、延迟、内容政策和数据处理条款。

### 5. 所有权与商业使用

- 官方当前说明：免费方案生成的图片公开显示并归 Recraft 所有，仅授予有限的个人用途许可，不能商业使用。
- 在付费订阅有效期间生成的资产由用户拥有并带有商业权利，订阅结束后仍保留这些权利。
- 资产的所有权状态在生成时确定；后来升级不会追溯改变免费方案旧资产的权利。
- 无论方案如何，官方限制把生成资产用于训练外部 AI 系统。

## 使用建议

1. 先确定最终需要位图还是矢量图，再选择模型与输出格式。
2. 品牌项目建立固定颜色、风格和构图规则，并保留提示词及版本记录。
3. 商业使用必须确认资产是在有效付费方案期间生成；免费方案结果不能直接商用。
4. AI 生成不保证自动避开商标、角色、人物肖像或其他受保护内容，仍需人工审查。
5. 导出 SVG 后在专业矢量软件中检查节点、路径、文字和印刷颜色。
