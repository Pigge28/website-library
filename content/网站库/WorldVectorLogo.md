# WorldVectorLogo

> [!abstract] 整体梗概
> WorldVectorLogo 是聚合品牌标志矢量文件的网站，可按名称搜索并下载 SVG Logo，也提供热门、下载排行、字母索引、贡献者和 API 等入口。它更适合作为“查找品牌标志源文件”的资料库，而不是品牌授权平台；Logo 的商标、版权和使用规范仍归相应权利人管理。

## 功能介绍

### 1. Logo 搜索与目录浏览

- 可直接输入品牌名搜索，也可按热门、下载量或字母顺序浏览。
- 单个 Logo 页面通常提供 SVG 预览与下载，适合演示稿、资料整理和设计参考。

### 2. 用户贡献与 API

- 网站提供 Add Logo 入口，说明数据库包含用户贡献内容；使用前应核对名称、比例、版本和官方品牌规范。
- API 可用于在应用或内容系统中检索 Logo，接入前需查看调用限制和服务条款。

### 3. 商标与版权边界

- 品牌标志通常受商标法、版权法及品牌指南约束。
- 不应把下载到的 Logo 改作自己的品牌、暗示官方合作，或用于未经许可的商品和宣传。
- 正式发布前应到品牌官网获取最新 Logo 包、颜色、留白和使用许可。
