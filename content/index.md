# 网站收藏与整理

> [!abstract] 使用方式
> 顶部索引会自动收集 `网站库` 中带有“类型：网站”属性的笔记。每个网站只设置一个“大分类”，具体功能使用可多选的“功能标签”描述；这样既能按大类分组，也能按功能组合筛选。

> [!important] 图片使用原则
> 各网站详情中的截图只用于展示部分页面、部分功能和大致界面，起到概览与辅助理解的作用。截图不代表网站的完整功能、全部栏目或实时状态；功能整理应结合官网资料与实际页面核对，不能仅依据截图作出完整性判断。

## 网站筛选表

![[网站库/网站索引.base#按大分类]]

> [!tip] 快速查找、筛选与跳转
> - 在表格顶部使用“搜索”，可按当前显示的名称、分类或功能标签检索。
> - 使用“筛选”选择 `功能标签`，可以查找同时具备模板、插件、教程或素材等功能的网站。
> - 网站名称会打开对应的详情笔记；“访问网站”会直接打开官网。
> - 新增网站时只需建立一份带标准属性的网站笔记，索引会自动更新，不必手工增加表格行。

## 分类机制

| 层级 | 属性 | 规则 |
| --- | --- | --- |
| 一级 | 大分类 | 每个网站只选一个，以网站最主要的用途为准 |
| 二级 | 功能标签 | 可以多选，用于描述模板、插件、教程、素材、社区等具体能力 |

### 当前大分类

| 大分类 | 收录范围 |
| --- | --- |
| CG与影视后期 | 面向动态设计、视频制作、影视后期、CG 学习及相关资源的网站 |
| 图片与视觉素材 | 提供摄影、插画、壁纸、透明 PNG、图标及其他视觉资产的网站 |
| AI创作与设计工具 | 以生成式 AI、视觉编辑、矢量设计和智能创作为主要用途的网站 |
| 表情与网络文化 | 提供 GIF、Meme、Emoji 查询、分享与网络社区内容的网站 |
| 字体与排版资源 | 提供字体下载、预览、授权核验及排版工具的网站 |
| 音乐与声音素材 | 提供音乐搜索、试听、下载或正版制作音乐授权的网站 |

> [!note] 分类原则
> 只有当新网站的主要用途与现有类别明显不同，才新增大分类。功能重合、仅资源类型不同的网站仍放在同一大类，用“功能标签”表达差异，避免分类层级持续膨胀。
